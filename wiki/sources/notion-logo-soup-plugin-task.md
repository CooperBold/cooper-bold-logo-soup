# Notion task "Logo Soup plugin"

The Cooper Bold Tasks database entry that started this repo: <https://app.notion.com/p/37afb6901a688069a9ebef05fe326252> (project 🚨 RapidSOS). Read-only; fetched 2026-10-19.

## The ask

Adapt the `sanity-labs/logo-soup` React package into a WordPress plugin, needed for the RapidSOS staging page `/public-safety/software-integrations/`, **and** release it as a free plugin under the Cooper Bold name.

## Comments worth knowing

- 2026-06-09: this work belongs to **Cooper Bold, not RapidSOS** (it is Cooper Bold's product).
- 2026-06-22: keep the task open to make it a full plugin, with Nicholas credited as the creator through Cooper Bold.
- 2026-07-01: WP.org does not want "Logo Soup" in the title because it implies a link to Sanity Labs. Name ideas: Balanced/Partner/Harmonized Logo Strip by Cooper Bold. Reply: don't feature Cooper Bold too much, so "Balanced Logos?".
- 2026-07-20: WP.org rejected "Balanced Logos" as too generic.
- 2026-07-29: "Logo Wrangler by Cooper Bold" proposed for its whimsy and approved; it was resubmitted as "Cooper Bold Logo Wrangler".

As of the fetch, the task status is still TODO with a due date of 2026-10-09. It is a live tracker, not a record of completion.
